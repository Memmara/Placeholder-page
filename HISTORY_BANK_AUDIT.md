# AQA GCSE History (8145) import

- Source: `work/history-source/aqa_gcse_history_8145/aqa_gcse_history_8145_question_bank.json` from the supplied archive.
- Imported: 735 original retrieval questions, 153 specification points, 16 taught options and two shared source/interpretation skill points.
- Course ID: `GCSE-HISTORY`. Question IDs and AQA references are preserved; platform curriculum IDs are `HIS-GCSE-C0001` to `HIS-GCSE-C0153`.
- Student plan: one period study, one wider world depth study, one thematic study and one British depth study. Shared skills are available to every History learner.
- Automatic coverage spreads available specification points within each chosen option across Years 9–11. Manual coverage uses the chosen option topics.
- The archive contains short-answer questions only, so History appears in Daily Mix and topic practice, while Speed Select continues to draw from selected subjects with multiple-choice questions.
- Supplied per-question rubrics, examples, idea rules, misconception feedback, source basis and review status are retained. Memmara automatically credits exact authored answers and single-mark examples, rejects only explicitly listed non-credit answers, and sends other wording to the existing criterion-by-criterion self-check. The supplied Python matcher is archived as reference code and is not executed by Memmara.
- The source labels the question bank a draft: conventions were sampled from four AQA June 2023 mark schemes and individual questions have not been verified against every past paper. Historic environment questions are generic because AQA's site changes by exam year.

Re-import from the retained source with `node work/import-history.mjs` inside the Memmara project. The import is idempotent for History records.
